PDF object and font decoding in `internal/pdf` is derived from github.com/ledongthuc/pdf at v0.0.0-20220302134840-0c2507a12d80, originally Go Authors code, under the retained BSD license. The local change exposes InterpretReader for concatenated page content streams. Text positioning follows the original crawler pypdf6.19.0 behavior; its implementation is repository-owned. Parsing runs in a worker-owned bounded subprocess; unsupported or malformed resources return failure.
